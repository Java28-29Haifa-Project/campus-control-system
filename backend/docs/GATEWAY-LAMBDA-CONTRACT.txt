GATEWAY <-> LAMBDA SERVICES CONTRACT

1. AUTH / IDENTITY SERVICE (SYNC)

1.1 LOGIN

Input (Gateway -> Lambda):
{
  "action": "LOGIN",
  "email": "email0@test.org",
  "password": "pass0"
}

Output (Lambda -> Gateway):
{
  "userId": "user0",
  "username": "name0",
  "email": "email0@test.org",
  "role": "USER"
}

1.2 VERIFY TOKEN

Input (Gateway -> Lambda):
{
  "action": "VERIFY_TOKEN",
  "userId": "user0"
}

Output (Lambda -> Gateway):
{
  "valid": true,
  "userId": "user0",
  "username": "name0",
  "email": "email0@test.org",
  "role": "USER"
}
