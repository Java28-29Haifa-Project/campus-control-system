# Полный мини-гайд по согласованию всех частей проекта (русский)

## Цель
Обеспечить корректное взаимодействие всех частей проекта: **Frontend (Amplify), API Gateway, Lambda, база данных и авторизация**, с минимальными усилиями для координации команд.

---

## 1. Сбор информации от команд

1. **Frontend команда:**
   - Endpoint API Gateway
   - Методы и структуры запросов
   - Тип авторизации (JWT/OAuth)
   - Тестовые токены или credentials

2. **Backend Lambda команда:**
   - Список функций и маршрутов
   - Event формат от Gateway
   - Доступ к базе данных (credentials или IAM Role)

3. **База данных:**
   - Доступный endpoint, credentials
   - Схема таблиц/структура данных
   - Доступность для Lambda

4. **Сервис авторизации:**
   - JWT issuer, audience
   - Endpoint проверки токена

> Собрать все данные в общий документ для команд.

---

## 2. Настройка API Gateway

1. Создать Stage (`dev`/`prod`) и маршруты для всех методов.
2. Включить CORS с origin фронтенда.
3. Настроить JWT Authorizer для маршрутов.
4. Интегрировать Lambda функции для каждого маршрута.
5. Деплоить Stage после изменений.

---

## 3. Проверка IAM и доверия между сервисами

1. Lambda должна разрешать вызов только API Gateway (Resource Policy).
2. Lambda имеет доступ к базе данных через IAM Role или credentials.
3. Frontend не имеет прямого доступа к Lambda или базе — только через Gateway.

---

## 4. Тестирование полного pipeline

1. **Gateway → Lambda:** проверка через Postman/curl с JWT.
2. **Lambda → База:** проверка чтения и записи.
3. **Frontend → Gateway → Lambda → База:** проверка полного flow.
4. Проверить CORS и авторизацию.
5. Использовать CloudWatch для логов и отлова ошибок.

---

## 5. Координация команд

- Назначить ответственного за интеграцию (координатор).
- Документировать endpoint, методы, авторизацию, CORS.
- Использовать Stage `dev` для тестов и `prod` для продакшена.
- Каждая команда отвечает за свою часть, координатор проверяет совместимость.
- Регулярные короткие синхронизации команд для устранения несоответствий.

---

## Итог
Следуя этому гайду, все части проекта взаимодействуют корректно и безопасно:
```
Frontend (Amplify) → API Gateway (CORS + JWT) → Lambda → Database
```
